# 📱 Coin Master Auto-Pilot Client App

The client UI is inspired by modern open-source minimal audio players like **Lastwave**. It features a dark frosted-glass aesthetic, responsive mobile controls, and a persistent bottom player notification bar.

---

## 🎮 How to Auto-Collect Free Spins

### Step 1: Open the App
- On your phone: Open Google Chrome and go to `http://<YOUR_PC_IP>:3000` (e.g., `http://192.168.1.15:3000`).
- You can tap **Add to Home screen** to install it like a native app.

### Step 2: Open Coin Master on your Phone
1. Launch Coin Master.
2. Wait for the slot machine village screen to load.
3. **Important**: Dismiss / close all startup pop-ups (event banners, spinning wheel, sale packs).

### Step 3: Start Auto-Collect
1. Tap **Collect All**.
2. Review the pre-flight checklist.
3. Select your delay (default: **4 seconds**).
4. Tap **"I've Closed Pop-ups • Start Collect"**.

### Step 4: Emergency Stop from Notification Bar
- While collecting, a floating notification bar appears at the bottom:  
  `Collecting [3/28] • 4s delay • 25 Free Spins`
- If you see any popup in the game saying *"This offer has ended"* or *"Reward already collected"*, tap the **STOP** button directly on the notification bar to immediately halt the queue.
